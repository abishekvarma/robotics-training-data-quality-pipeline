# Deploy the demo

## Streamlit Community Cloud
1. Create a public GitHub repository and upload this folder.
2. Open Streamlit Community Cloud.
3. Select the repository.
4. Set the main file to `app.py`.
5. Deploy.

The repository also contains the local Python and PySpark pipeline source, raw sample data, quality report, architecture, tests, and LinkedIn post draft.

## GitHub
Recommended repository name:

`robotics-training-data-quality-pipeline`

Recommended description:

`Data Engineering POC: multimodal robotics sensor ingestion, validation, deduplication and curated training-data pipeline using Python and PySpark.`

## LinkedIn
Use `docs/LINKEDIN_POST.md` after the GitHub repository is public. Replace `[PASTE GITHUB LINK]` with the repository URL.

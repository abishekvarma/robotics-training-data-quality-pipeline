## Portfolio description

### Robotics Training Data Quality Pipeline

Built a Data Engineering proof-of-concept for validating raw multimodal sensor events before they reach a curated, training-ready dataset.

Implemented schema validation, missing-value checks, numeric validation, duplicate detection, sensor-range checks, rejected-record traceability, curated outputs and a PySpark version of the processing flow.

**Stack:** Python, PySpark, ETL, Data Quality, SQL concepts, Azure architecture mapping.

The project focuses on transferable Data Engineering skills rather than robotics modeling or ML training.
